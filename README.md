# ::Notation – Die Semantische Promptnotation für KI

Die Semantische Promptnotation nutzt den Operator `::`, um Begriffe, Rollen und Bedeutungsräume kontextuell zu verknüpfen. Sie macht Sprache, Daten und Code für **Künstliche Intelligenz** maschinenlesbar, steuerbar und konsistent. Damit wird Prompting reproduzierbar, disambiguierbar und effizient – von SEO-Optimierungen über KPI-Dashboards bis hin zur automatisierten Codegenerierung.  
Entwickelt und beschrieben 2025 von Joost Schloemer (CC BY 4.0).

---

## Grundlage
- `::` ist kein reines Syntaxzeichen, sondern ein **semantischer Operator**.  
- Er verbindet Konzepte in einer **klar strukturierten Kette** (`::kette`) statt in losem Text.  
- Ziel: **Ambiguität reduzieren, Bias sichtbar machen und Prozesse disambiguieren**.  
- Ergebnis: Inhalte, Daten und Code werden **maschinen- und menschenverständlich**.

---

## Syntax-Elemente
- **Operatoren**: `::intake`, `::rolle`, `::ausgabe`, `::kette`
- **Separatoren**:  
  - `;;` → trennt mehrere Aussagen/Parameter  
  - `||` → parallele Optionen oder Stränge  
  - `>>` → Folgesequenzen / nächste Schritte  

---

**Beispiel:**
```txt
::intake=Keyword-Analyse  
::rolle=SEO-Coach  
::ausgabe=::Analyse::;;::Schlussfolgerung::
